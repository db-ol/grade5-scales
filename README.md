# 五级音阶抽考

ABRSM 钢琴五级（Practical Grades）音阶与琶音的手机自测网页。像考试一样随机抽题，模拟考官用英文语音点题，可以听示范、开节拍器、给自己打分，还能做一轮音阶琶音模拟考试。

纯静态网页，不需要服务器。第一次打开需要联网，加到主屏幕以后可以离线使用。

## 覆盖的考试范围

依据 ABRSM Piano Practical Grades 大纲 2025 & 2026 第 35 页（五级）和第 13 到 14 页（音阶琶音规则）。2027 & 2028 新大纲（2027 年 1 月 1 日起使用）更新了曲目，五级音阶琶音的要求和旧版完全相同，2021 年以来没有变过。2025 & 2026 大纲可以用到 2027 年 12 月 31 日。

| 题型 | 内容 | 音域 | 要求 |
| --- | --- | --- | --- |
| 音阶（同向） | A、E、B、升F、降D 大调。升f、升c、升g、降e、降b 小调（和声或旋律，考生自选） | 两个八度 | 连奏，双手 |
| 断奏音阶 | 降A 大调。f 小调（和声或旋律，考生自选） | 两个八度 | 断奏，分手 |
| 反向音阶 | 降D 大调。升c 和声小调 | 两个八度 | 连奏，双手从主音同音开始 |
| 反向半音阶 | 左手从升F、右手从升A开始 | 两个八度 | 连奏，双手相隔大三度开始 |
| 琶音 | A、E、B、升F、降A、降D 大调。升f、升c、升g、降e、f、降b 小调 | 两个八度 | 连奏，双手 |
| 减七和弦琶音 | 从 B 开始 | 两个八度 | 连奏，分手 |

一共 31 张卡片（分手的项目左右手各一张）。

* 全部背谱，音符均匀，不用踏板，琶音只要求原位。双手一起弹时两手相隔一个八度（反向的两项除外）。
* 同向音阶和断奏音阶里的小调由考生自选和声或旋律，考官不指定。反向音阶的升c小调规定弹和声小调。
* 考官通常每种题型至少问一项，同类先大调后小调，分手项目会兼顾左右手。考官会说出调名或起始音，分手项目会说左手还是右手。
* 速度参考（大纲写的是 a general guide）：音阶 二分音符 = 60，琶音 二分音符 = 44，都按每拍四个八分音符计。
* 评分：音阶与琶音满分 21 分（总分 150）。优秀 19 到 21，良好 17 到 18，及格 14 到 16。

## 功能

* **抽题**：按熟练度加权随机抽题（没弹好的多抽，很熟练的少抽），可按题型筛选。可以只听不看，模拟听考官点题。
* **考官语音**：用手机自带的语音合成朗读英文指令，优先英式英语声音，可换成中文提示。
* **听示范**：网页内置合成器按大纲参考速度弹出正确的音，键盘上同步亮键。可自选形式的小调可以切换和声或旋律示范。
* **节拍器**：按参考速度打拍，可在设置里放慢到 60% 或 80%。
* **模拟考试**：6、10 或 14 项，按大纲写明的出题习惯组卷，考完逐项自评。
* **考试范围**：全部 31 项的清单和熟练度，附大纲规则要点和评分标准。

练习记录只存在本机浏览器里。

## 本地运行

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 测试

```sh
node --test tests/*.test.js
```

测试会核对卡片与大纲表格逐项一致，检查每一项示范的音名拼写、音域、上下行和双手关系，并随机生成几千份模拟考卷检查出题规则。

## 部署到 GitHub Pages

1. 把这个文件夹推到一个 GitHub 仓库（免费账号需要公开仓库，网页本身也是公开的）。
2. 仓库 Settings → Pages → Build and deployment，Source 选 Deploy from a branch，分支选 `main`，目录选 `/ (root)`。
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

离线缓存采用网络优先，在线打开就会拿到最新文件。增删文件时记得同步 `sw.js` 里的文件列表，并改一下 `VERSION`。

## 文件

* `index.html`，`css/style.css`：页面和样式
* `js/theory.js`：音名拼写、音阶琶音的音列
* `js/syllabus.js`：五级大纲数据、卡片、考官说法、示范音列、模拟考卷
* `js/speech.js`：语音朗读
* `js/audio.js`：示范合成器和节拍器
* `js/keyboard.js`：键盘图
* `js/app.js`：页面逻辑
* `sw.js`，`manifest.webmanifest`，`icons/`：离线和添加到主屏幕
* `fonts/`：Bodoni Moda 和 Noto Music 的子集（SIL Open Font License，许可证见同目录）
* `tools/build-artifact.js`：把整个网页打包成单个 HTML 文件
